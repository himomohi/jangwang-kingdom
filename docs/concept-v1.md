# 잔광왕국 — 컨셉 v1 (잠금)

## 한 줄
늦을 90년대 한국 탑다운 판타지 MMO **감성**의 오리지널 SP 액션 RPG. Actoz Soft《마지막왕국1》자산·명칭·맵·캐릭터 **비복제**.

## 플레이 루프
탐험 → 전투 → 룻 → 장착 → 성장 → 전직 → 마을 → 재탐험

## 룩
- 유럽 판타지 왕국 픽셀 탑다운 (조선/한복 아님)
- 16색 LOCKED 팔레트, `#000` 아웃라인 금지
- 코드젠 본체 우선, PNG 아틀라스는 선택 오버레이
- 주광 북서, 후처리 꺼도 읽힘

## 법적
상표·원작 캐릭터·맵·스킬명·UI 아트 사용 금지. 호모지(감성 오마주)만.
